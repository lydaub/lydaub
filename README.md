#### 🎯 Featured Project: Unwrapping Customer Delight: Optimizing Surprise Gift Strategies with Randomized Controlled Trials and MLRATE
Check out my work on this data analysis project for Estée Lauder! My team and I developed a model to measure the impact of surprise gifts on customer spending using machine learning and provide insights for marketing ROI.

Tools: Python, Pandas, NumPy, scikit-learn, Jupyter Notebook, matpoltlib, statsmodels, seaborn, SciPy

What We Did: We employed the Machine Learning Regression-Adjusted Treatment Effect Estimator (MLRATE) to robustly quantify the return on investment for surprise gift campaigns, compared estimated treatment effects with simulated true effects and derived insights for optimizing future gift-giving strategies

Results: Explained 67.1% of revenue variance (vs 1.1% in standard model), reduced standard error by 42%, narrowed confidence interval by 42%, achieved same statistical power with 68% fewer customers needed, and provided insights that helped guide data-driven improvements in revenue.
